## 二、运行方式

### 环境要求
| 工具 | 版本 | 说明 |
| --- | --- | --- |
| JDK | 17 | Project SDK 与 Module SDK 两处均需检查 |
| Maven | 3.9+ | 自带 Maven Wrapper 亦可 |
| JavaFX | 17.0.20 | 已通过 Maven 依赖引入，无需单独安装 |

### 构建
```bash
mvn clean compile
```

### 运行（JavaFX 从 JDK 11 起已剥离，**不能直接 `java -jar`**）
方式一（推荐，命令行）：
```bash
mvn javafx:run
```
方式二（IDEA）：
1. 打开 Maven 面板 → `untitled1` → `Plugins` → `javafx` → 双击 `javafx:run`；
2. 或以 Debug 方式启动该 Maven 目标进行断点调试（课程要求使用 Debug 而非 System.out.println）。

## 五、Git 使用约定

- 分支模型：`main`（稳定，仅合入）→ `dev`（开发主干）→ `feature/*`（功能分支，命名如 `feature/score`）
- 新功能一律从 `dev` 切出 `feature/*`，完成后合回 `dev`，评审后再合入 `main`
- 提交信息规范：`<type>: <简述>`，type 取值 `feat / fix / docs / refactor / chore / test`
- 里程碑打 tag：当前 `v0.0.1-skeleton`；后续按阶段递增
- 禁止提交：`target/`、`.idea/`、`*.iml`、`logs/`（见 .gitignore）
- 全仓库统一 UTF-8，`.editorconfig` 已随仓库提交
