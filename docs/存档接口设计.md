# 存档系统接口文档

> 版本：v1.0 · 日期：2026-09-08 · 模块：存档系统（Save System）
> 角色：存档系统负责人 · 状态：**待组长评审**
> 依据：《宝可梦、技能、队伍接口文档》§3.3（PokemonState）；《天气系统汇总》
> 依赖方：UI模块、战斗系统、游戏流程系统、图鉴（物种/道具注册表）

## 1. 概述

### 1.1 模块定位

存档系统负责**世界状态快照与进行中战斗的捕获、编解码、磁盘读写与恢复**。目标场景：

- **世界存档**：队伍内每只宝可梦（当前 HP、能力阶级）+ 出战位 + 背包数量，对战之外随时保存/读取。
- **战斗续档**：对局中途退出或断线后，可从存档恢复**同一场**进行中的对战（回合数、天气、天气剩余回合、等待派出/击倒轮换标记、双方队伍、对局历史）。

### 1.2 对外提供的服务

| 服务 | 说明 | 使用方 |
|------|------|--------|
| 世界存档捕获/恢复 | 玩家队伍与背包的采样、重建 | UI、游戏流程 |
| 战斗中途存档/续档 | 整场对局状态的快照与 `Battle` 重建 | 战斗系统、UI |
| 文件编解码与 IO | 自定文本格式 ↔ 内存对象；UTF-8 磁盘读写 | 全部上层 |
| 物种/道具名称注册表 | 按名重建宝可梦与道具唯一实例 | 存档、图鉴 |

### 1.3 设计约束

- 纯 JDK 实现，**不引入 JSON 等第三方序列化依赖**。
- 存档只存「名称 + 可变状态」，种族值 / 努力值 / 招式由注册表重建（格式稳定、体积小）。
- 包位置：`com.bao01.save`（实现文件：`SaveData.java`、`SaveManager.java`、`SaveException.java`）。


## 2. 数据模型（Model）

> 全部数据模型为不可变 `record`，定义于 `com.bao01.save.SaveData` 内。

### 2.1 SaveData（存档数据容器）

```java
package com.bao01.save;

public final class SaveData {

    public static final int FORMAT_VERSION = 1;   // 当前存档格式版本

    private SaveData() { }                        // 纯容器，禁止实例化
}
```

### 2.2 World（世界存档 · 顶层）

```java
public record World(int version, TeamData playerTeam, BattleData battle) {
    public boolean hasBattle();   // battle != null：当前处于对局中
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `version` | `int` | 格式版本号，读入高于 `FORMAT_VERSION` 时拒绝加载 |
| `playerTeam` | `TeamData` | 玩家队伍 + 背包（必填） |
| `battle` | `BattleData` | 进行中战斗的快照；`null` 表示对战外 |

### 2.3 PokemonData（宝可梦快照）

```java
public record PokemonData(String species, int level, int hp, int[] stages) {

    // 采样：运行态 → 数据
    public static PokemonData capture(Pokemon p);

    // 重建：数据 → 运行态（未知物种返回 null）
    public Pokemon restore();

    public String describe();
}
```

- `species`：物种名（`SamplePokemon` 注册表按名重建，含种族/努力/招式）。
- `hp`：当前 HP，`0` 表示濒死（重建时按 `min(hp, maxHp)` 夹紧）。
- `stages`：六项能力阶级，顺序固定为 `Stat.values()`（HP、物攻、物防、特攻、特防、速度），取值 ±6。

### 2.4 ItemData（道具快照）

```java
public record ItemData(String itemName, int count) {

    public static ItemData capture(Item item, int count);
    public Item restore();   // Items.byName 解析；未知道具返回 null
}
```

> 以**名称**保存、按 `Items` 注册表解析回唯一实例——保持 `Bag` 以实例为键（identity key）的语义。

### 2.5 TeamData（队伍快照）

```java
public record TeamData(List<PokemonData> members, int activeIndex, List<ItemData> bag) {

    public static TeamData capture(Team team);
    public Team restore();   // 未知物种成员跳过；全员不可用抛 SaveException
}
```

- `members`：按队伍存储顺序排列（1~6 只）。
- `activeIndex`：当前出战位；恢复时若指向濒死/越界则回退第一只存活成员。
- `bag`：背包内每种道具及其数量。

### 2.6 BattleData（战斗快照）

```java
public record BattleData(
        String opponent,              // Battle.Opponent 名称：WILD / TRAINER
        int roundNo,                  // 已进行回合数
        String weather,               // Weather 名称：NONE/SUN/RAIN/SAND/SNOW
        int weatherTurnsLeft,         // 天气剩余回合（含本回合）
        boolean playerPendingSendout, // 是否等待玩家派替补
        boolean playerKoSwitchPending,// 是否等待玩家决定击倒轮换
        TeamData foeTeam,             // 敌方队伍 + 背包
        List<String> history) {       // 全局对局日志

    public static BattleData capture(Battle b);
    public Battle.Opponent opponentEnum();   // 字符串 → 枚举（含校验）
    public com.bao01.model.Weather weatherEnum();
}
```


## 3. 注册表与恢复机制（Rebuild）

> 存档不落盘静态数据，恢复依赖下述「按名重建」入口。

### 3.1 SamplePokemon（物种注册表）

```java
package com.bao01.config;

public final class SamplePokemon {

    /** 按物种名与等级生成基础宝可梦（满 HP、0 阶级）；未知物种返回 null。 */
    public static Pokemon create(String speciesName, int level);

    /** 当前图鉴收录的全部物种名。 */
    public static Set<String> speciesNames();
}
```

### 3.2 Items（道具注册表）

```java
package com.bao01.config;

public final class Items {

    public static final Item POTION;        // 伤药（heal 50）
    public static final Item SUPER_POTION;  // 好伤药（heal 120）
    public static final Item FULL_RESTORE;  // 全满药（fullHeal）

    /** 按名称取唯一实例；未知名称返回 null。 */
    public static Item byName(String name);

    public static Set<String> itemNames();
}
```

### 3.3 Battle.resumed（战斗恢复工厂）

```java
package com.bao01.model;

public final class Battle {

    /** 从存档恢复：不重置双方队伍，沿用回合/天气/轮换标记/历史。 */
    public static Battle resumed(Team player, Team foe, Battle.Opponent opponent,
                                 int roundNo, Weather weather, int weatherTurnsLeft,
                                 boolean playerPendingSendout,
                                 boolean playerKoSwitchPending,
                                 List<String> history);
}
```

### 3.4 恢复流程

```
读取存档文本
  → World（校验版本号 ≤ FORMAT_VERSION）
    → playerTeam.restore()  重建玩家 Team（按名重建宝可梦 → 还原 HP/阶级 → 背包）
    → battle 非空?
        → foeTeam.restore() 重建敌方 Team
        → Battle.resumed(...) 得到可继续操作的进行中对局
```


## 4. 服务接口（Service）

### 4.1 SaveManager（存档服务门面）

```java
package com.bao01.save;

import java.nio.file.Path;

public final class SaveManager {

    // ============ 捕获（运行态 → World） ============
    /** 对战外：玩家队伍 + 背包。 */
    public static SaveData.World captureWorld(Team playerTeam);

    /** 对局中：玩家队伍 + 战斗快照（对局已结束时 battle 为 null）。 */
    public static SaveData.World captureBattle(Battle battle);

    // ============ 恢复（World → 运行态） ============
    public static Team restorePlayerTeam(SaveData.World world);   // 仅队伍
    public static Battle restoreBattle(SaveData.World world);     // 需 hasBattle()

    // ============ 编解码 ============
    public static String toText(SaveData.World world);
    public static SaveData.World fromText(String text);

    // ============ 磁盘 IO ============
    public static Path defaultPath();            // {user.home}/.bao01/save.txt
    public static void writeToFile(Path path, SaveData.World world);
    public static SaveData.World readFromFile(Path path);
}
```

### 4.2 SaveException（存档异常）

```java
package com.bao01.save;

/** 读写 / 解析 / 恢复失败时抛出的运行时异常。 */
public class SaveException extends RuntimeException {
    public SaveException(String message);
    public SaveException(String message, Throwable cause);
}
```


## 5. 存盘文件格式（Codec）

- 编码：UTF-8；首行魔数 `BAO01SAVE`。
- 解析时忽略空行与 `#` 注释行；标记错位 / 字段不足 / 数字非法均抛 `SaveException` 并携带行内容。

| 行前缀 | 含义 | 示例 |
|--------|------|------|
| `VERSION` | 格式版本 | `VERSION 1` |
| `PT` / `FT` | 队伍头（成员数 + 出战位） | `PT 1 0` |
| `POKE` | 宝可梦：物种｜等级｜HP｜六阶级 | `POKE 焰尾狐|50|65|0,0,0,0,0,2` |
| `BAG` | 背包条目数 | `BAG 2` |
| `ITEM` | 道具：名称｜数量 | `ITEM 伤药|1` |
| `BATTLE` | 是否含战斗（1/0） | `BATTLE 1` |
| `OPP` | 对战对象（WILD/TRAINER） | `OPP WILD` |
| `ROUND` | 回合数 | `ROUND 2` |
| `WEATHER` | 天气 名称 剩余回合 | `WEATHER SUN 3` |
| `PEND` | 等待派出 / 等待击倒轮换 | `PEND 0 0` |
| `HIST` / `H` | 历史条数 / 单条日志 | `H ————— 第 2 回合 —————` |

完整示例（第 2 回合，大晴天剩余 3 回合）：

```
BAO01SAVE
VERSION 1
PT 1 0
POKE 焰尾狐|50|65|0,0,0,0,0,2
BAG 2
ITEM 伤药|1
ITEM 好伤药|1
BATTLE 1
OPP WILD
ROUND 2
WEATHER SUN 3
PEND 0 0
FT 1 0
POKE 青藤蜥|50|47|0,-1,0,0,0,0
BAG 0
HIST 3
H ————— 第 1 回合 —————
H 我方派出了 焰尾狐！ 使用了大晴天！
H ————— 第 2 回合 —————
```

## 6. 健壮性、扩展与验证

### 6.1 健壮性

| 场景 | 行为 |
|------|------|
| 版本号高于当前 | 拒绝加载（防旧客户端读新档） |
| 未知物种 / 道具 | 跳过该项；全部成员不可恢复才抛异常 |
| 出战位濒死 / 越界 | 回退第一只存活成员 |
| 文件缺失 / 标记错位 | 抛 `SaveException`（含路径或行内容） |

### 6.2 向后兼容扩展

- 新增字段按「末尾追加 + 可选默认值」设计；`FORMAT_VERSION` 需要时递增。
- 预留给未来的扩展点：携带道具、特性、个体值（IV）、技能 PP、努力值、异常状态等——只需给 `PokemonData` / `BattleData` 增字段并升级版本。

### 6.3 验证

`com.bao01.SaveDemo`（无头主程序）实测输出：

```
对局状态：回合 2，天气 SUN 剩余 3，是否结束 false
恢复状态一致: true
磁盘读取一致: true
恢复后继续对战 1 回合，结果 PLAYER_WON
世界存档回环: 出战 焰尾狐 HP 65/135 背包(伤药) 2
```
