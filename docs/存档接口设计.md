# 存档系统接口文档

> 版本：v1.2 · 日期：2026-09-10 · 模块：存档系统（Save System）
> 角色：存档系统负责人 · 状态：**待组长评审**
> 依据：dev 数据注册表 `org.example.data.GameData`（物种/道具按 id 重建）；《宝可梦、技能、队伍接口文档》§3.3（PokemonState）
> 依赖方：UI / 主循环、游戏流程模块、养成模块（战斗系统经 feature/battle 独立演进）

## 1. 概述

### 1.1 模块定位

存档系统负责**世界状态（一名玩家的队伍 + 背包）的捕获、编解码、磁盘读写与恢复**。目标场景：

- **世界存档**：队伍内每只宝可梦（物种 id、等级、当前 HP）+ 出战位 + 背包（道具 id、数量），对战之外随时保存/读取。

> 本模块只保存「玩家对象」层面的世界状态，**不保存对局过程**（回合、天气、轮换标记等归战斗模块）；战斗续档由 feature/battle 分支另行设计。

### 1.2 对外提供的服务

| 服务 | 说明 | 使用方 |
|------|------|--------|
| 世界存档捕获/恢复 | `org.example.model.Player` 采样 → `World`；`World` → 重建 `Player` | UI、游戏流程 |
| 文件编解码与 IO | 自定文本格式 ↔ 内存对象；UTF-8 磁盘读写 | 全部上层 |

### 1.3 设计约束

- 纯 JDK 17 实现，**不引入 JSON 等第三方序列化依赖**。
- 运行在 **dev 的 `org.example` 对象模型**上：捕获/恢复的对象是 `Player`（及其 party/bag）。存档只存「id + 可变状态」，种族 / 招式由注册表按 id 重建（格式稳定、体积小）。
- 只依赖 `org.example` 的公共 API，**不修改 org.example / dev 任何文件**。
- 包位置：`com.bao01.save`（实现文件：`SaveData.java`、`SaveManager.java`、`SaveException.java`、`SaveDemo.java`）。
- 自测入口：`com.bao01.save.SaveDemo`（无头可运行，不依赖 UI / 游戏流程 / 战斗模块）。

## 2. 数据模型（Model）

> 全部数据模型为不可变 `record`，定义于 `com.bao01.save.SaveData` 内；仅用于「落盘 / 传输」，不承载行为。

### 2.1 SaveData（存档数据容器）

```java
package com.bao01.save;

public final class SaveData {

    public static final int FORMAT_VERSION = 1;        // 当前存档格式版本

    /** 恢复玩家时使用的默认训练家名。 */
    public static final String DEFAULT_PLAYER_NAME = "训练家";

    private SaveData() { }                             // 纯容器，禁止实例化
}
```

### 2.2 World（世界存档 · 顶层）

```java
public record World(int version, PlayerData player) {
    // 紧凑构造：player 不可为 null
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `version` | `int` | 格式版本号，读入高于 `FORMAT_VERSION` 时拒绝加载 |
| `player` | `PlayerData` | 玩家快照（队伍 + 出战位 + 背包，必填） |

### 2.3 PartyEntry（宝可梦快照）

```java
public record PartyEntry(String speciesId, int level, int currentHp) {

    // 采样：运行态 → 数据
    public static PartyEntry capture(Pokemon p);

    // 重建：数据 → 运行态（未知物种返回 null）
    public Pokemon restore();

    public String describe();
}
```

- `speciesId`：物种 id（`s_*`），由 `GameData` 注册表按 id 重建（含种族/招式）。
- `level`：等级；`currentHp`：当前 HP，`0` 表示濒死。
- `restore()`：`GameData.instance().createPokemon(speciesId, level)` 生成满状态个体后按 `min(hp, maxHp)` 截回当前 HP。
- 能力阶级（stages）不再落盘：当前 `org.example.model.Pokemon` 尚无阶级字段，需要时再按 §6.2 追加。

### 2.4 ItemEntry（道具快照）

```java
public record ItemEntry(String itemId, int count) {

    public static ItemEntry capture(ItemStack stack);   // stack.getItem().getId() / getCount()
    public Item restore();                               // GameData.instance().item(itemId)；未知 id 返回 null
}
```

> 以 **id** 保存、按 `GameData.item(id)` 解析回注册表实例。`Bag` 以实例为键计数（每堆叠一个 `ItemStack`）。

### 2.5 PlayerData（玩家快照）

```java
public record PlayerData(List<PartyEntry> party, int activeIndex, List<ItemEntry> bag) {

    public static PlayerData capture(Player player);     // 全队采样 + 非空背包堆叠采样
    public Player restore();                             // 默认训练家名（DEFAULT_PLAYER_NAME）
    public Player restore(String playerName);
}
```

- `party`：按队伍存储顺序排列（1~6 只）。
- `activeIndex`：当前出战位；恢复时若指向濒死/越界则 `leadWithFirstHealthy()` 回退到第一只存活成员。
- `bag`：背包内每种道具及其数量。
- `restore()`：`new Player(name)` → `addToParty` 逐只重建 → `getBag().add(item, count)` 回填背包；未知物种/道具的条目跳过，**全员不可恢复时抛 `SaveException`**。

### 2.6 运行态对象（不序列化 · 归属 dev 的 org.example）

存档捕获/恢复针对以下 dev 公共类型（签名以 dev 实际代码为准）：

- `org.example.model.Player`：`getParty()`（只读 List）、`addToParty(Pokemon)`、`getActiveIndex()`、`setActive(int)`、`leadWithFirstHealthy()`、`healParty()`、`getBag()`。
- `org.example.model.Pokemon`：`getSpecies().getId()`、`getName()`、`getLevel()`、`getCurrentHp()`、`getMaxHp()`、`takeDamage(int)`、`heal(int)`、`isFainted()`。
- `org.example.model.Item` / `ItemStack`（`getItem()` / `getCount()` / `isEmpty()`）。
- `org.example.data.GameData`：`instance()`、`item(String id)`、`createPokemon(String id, int level) → Optional<Pokemon>`。

## 3. 注册表与恢复机制（Rebuild）

> 存档不落盘静态数据，恢复依赖 dev 的 `GameData` 注册表「按 id 重建」。

### 3.1 GameData（物种 / 道具注册表 · dev 提供）

```java
package org.example.data;

public final class GameData {
    public static GameData instance();

    /** 按道具 id 取注册表唯一实例；未知 id 返回 null。 */
    public Item item(String id);

    /** 按物种 id 与等级生成一只基础宝可梦（满 HP）；未知 id 返回 Optional.empty。 */
    public Optional<Pokemon> createPokemon(String id, int level);

    /** 图鉴收录的全部物种 / 道具。 */
    public List<Species> allSpecies();
    public List<Item> allItems();
}
```

> 数据源为 dev 的 `src/main/resources/data/species.csv` 与 `items.csv`；物种/道具 id 形如 `s_fire_cat`、`i_potion`。

### 3.2 恢复流程

```
读取存档文本
  → World（校验 version ≤ FORMAT_VERSION）
    → player.restore()
        GameData.createPokemon(speciesId, level) → 还原 HP（截回 maxHp）→ addToParty
        背包 GameData.item(itemId) → player.getBag().add(item, count)
        activeIndex 有效且非濒死 → setActive；否则 leadWithFirstHealthy()
```

## 4. 服务接口（Service）

### 4.1 SaveManager（存档服务门面）

```java
package com.bao01.save;

import org.example.model.Player;
import java.nio.file.Path;

public final class SaveManager {

    // ============ 捕获（Player → World） ============
    /** 世界存档：玩家队伍 + 背包。 */
    public static SaveData.World captureWorld(Player player);

    // ============ 恢复（World → Player） ============
    public static Player restorePlayer(SaveData.World world);
    public static Player restorePlayer(SaveData.World world, String playerName);

    // ============ 编解码 ============
    public static String toText(SaveData.World world);
    public static SaveData.World fromText(String text);

    // ============ 磁盘 IO ============
    public static Path defaultPath();                 // {user.home}/.bao01/save.txt
    public static void writeToFile(Path path, SaveData.World world);   // 自动建父目录
    public static SaveData.World readFromFile(Path path);
}
```

### 4.2 SaveException（存档异常）

```java
package com.bao01.save;

/** 读写 / 解析 / 恢复失败时抛出的运行时异常。 */

    public SaveException(String message);
    public SaveException(String message, Throwable cause);

```

## 5. 存盘文件格式（Codec）

- 编码：UTF-8；首行魔数 `BAO01SAVE`。
- 解析时忽略空行与 `#` 注释行；标记错位 / 字段不足 / 数字非法均抛 `SaveException` 并携带行内容。

| 行前缀 | 含义 | 示例 |
|--------|------|------|
| `VERSION` | 格式版本 | `VERSION 1` |
| `PT` | 队伍头（成员数 + 出战位） | `PT 2 0` |
| `POKE` | 宝可梦：物种id｜等级｜当前HP | `POKE s_fire_cat|50|45` |
| `BAG` | 背包条目数 | `BAG 1` |
| `ITEM` | 道具：道具id｜数量 | `ITEM i_potion|2` |

完整示例：

```
BAO01SAVE
VERSION 1
PT 2 0
POKE s_fire_cat|50|45
POKE s_water_tad|48|44
BAG 1
ITEM i_potion|2
```

## 6. 健壮性、扩展与验证

### 6.1 健壮性

| 场景 | 行为 |
|------|------|
| 版本号高于当前 | 拒绝加载（防旧客户端读新档） |
| 未知物种 / 道具 | 跳过该项；全部成员不可恢复才抛异常 |
| 出战位濒死 / 越界 | `leadWithFirstHealthy()` 回退第一只存活成员 |
| 文件缺失 / 标记错位 | 抛 `SaveException`（含路径或行内容） |

### 6.2 向后兼容扩展

- 新增字段按「末尾追加 + 可选默认值」设计；`FORMAT_VERSION` 需要时递增。
- 预留给未来的扩展点：能力阶级（stages）、个体值（IV）、技能 PP、携带道具、异常状态等——只需给 `PartyEntry` 增字段并升级版本。

### 6.3 验证

- 编译校验：`mvn clean compile`（连同游戏流程模块）。
- **自测入口 `com.bao01.save.SaveDemo`**：无头运行，覆盖 38 项断言，全部通过退出码 0，任一失败退出码 1。

```bash
mvn clean compile
java -cp target/classes com.bao01.save.SaveDemo
```

| 用例组 | 覆盖点 |
|--------|--------|
| 1. 内存采样 → 重建回环 | 队伍只数、每只物种 / 等级 / 当前 HP / 濒死标记、出战位、背包逐项比对 |
| 2. 文本编解码 | 头标记 / VERSION / POKE / ITEM 行；`capture → restore → capture` 文本稳定 |
| 3. 磁盘读写回环 | 写盘建父目录、读回与内存文本一致、读回后可重建玩家（落地 `target/save-demo.txt`） |
| 4. 出战位濒死回退 | 出战位指向濒死成员时回退第一只存活成员 |
| 5. 未知 id 跳过 | 未知物种 / 未知道具跳过；全员不可恢复抛 `SaveException` |
| 6. 非法存档拒绝 | 空文本、缺头标记、字段不足、版本过新、文件不存在均被拒 |

- 后续可将该自测用例转写为 JUnit 用例纳入测试计划（当前工程尚未引入测试依赖）。
