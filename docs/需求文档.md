# PokeRouge 需求文档（v0.1 草稿）

## 一、项目概述

### 1.1 项目背景与目标
基于**宝可梦回合制对战玩法**的 **Roguelike 类游戏**：玩家组建并培养宝可梦队伍，在一次次随机生成的冒险（Run）中不断变强，挑战愈发强大的敌人。经典回合制养成 × 肉鸽爬塔循环。

### 1.2 术语表
| 术语 | 含义 |
| --- | --- |
| Run（一局） | 从组建队伍出发到通关或失败的全过程 |
| AP（行动点） | 每段路线的行动额度，决定可进入的随机节点数量 |
| 段（阶段） | 路线地图的推进单位，行动点耗尽触发道馆战 |
| EV / 努力值 | 可分配属性，与该物种抓捕次数挂钩 |
| 性格（Nature） | 影响基础属性加成/削弱的属性 |
| 濒死 | HP 归零，无法参战，需医院或道具恢复 |

## 二、用户与场景
| 用户 | 核心诉求 |
| --- | --- |
| 玩家 | 在单局随机路线中完成养成构筑、策略决策、挑战通关 |
| 玩家 | 通过抓捕 → 努力值/合并/性格，形成差异化构筑 |

## 三、核心玩法循环

> 初始选队 → 按段路线（AP 内自主选节点：路人/野外/医院/商店/特殊事件）→ AP 耗尽触发道馆战 → 敌人增强、进入下一段 → 后期火箭队剧情分支 → 四天王连打 → Boss 冠军战 →（条件触发首领侵略战）→ 通关或结束 Run

### 3.1 队伍养成途径（四条成长线）
| 途径 | 说明 |
| --- | --- |
| 等级成长与进化 | 战斗积累经验升级，达标进化，解锁更强种族值与技能 |
| 商店购买 | 随机节点商店中金币购买道具、回复品、技能机 |
| 宝可梦抓捕 | 削弱后抓捕野生宝可梦扩充备选队伍 |
| 技能学习 | 升级习得 / 技能机传授，替换打磨技能 |

### 3.2 特色机制 A：努力值培养（EV）
- 宝可梦具备可分配的努力值属性，影响攻击、防御、速度等基础面板；
- **抓捕次数越多，该物种对应努力值成长越快/越高**；
- 目的：将「抓捕行为」与「队伍养成」绑定，形成独特构筑策略。

### 3.3 特色机制 B：宝可梦性格
- 性格对攻击/防御/速度等基础属性产生加成或削弱，同一物种可走出不同培养方向；
- **同类合并，等级取高**：捕获同种时合并为单个个体，等级取当前最高；
- **性格可自由选择**：合并后性格由玩家自行选择（如爽朗：+速-物攻），按阵容定向调整；
- 作用：缓解重复抓捕冗余，使重复捕获兼顾努力值与资质优化。

### 3.4 特色机制 C：可携带装备（已实现）
- 每只宝可梦拥有一个**装备槽**，可穿戴一件可携带装备；**同一件装备全库唯一**，穿给另一只时自动脱下原穿戴者；
- 装备不是消耗品，效果**带入局内**，由战斗引擎自动结算；
- 装备清单以 **`src/main/resources/data/equipment.csv` 为准**（当前 **77 件**：47 件道具 + 30 种树果；
  下表为最早的 8 件示例，仅作对照）；
  > **口径更新**：需求方 58 行道具对照表中，**有 9 件已裁决从需求中移除**（紧缠勾爪 / 机变骰子 /
  > 逃脱按键 / 避难背包 / 红牌 / 美丽空壳 / 厚底靴 / 红线 / 特性护具），**不实现且不建数据行**，
  > 原因见 `QA问题表.md` 第 46 条。装备效果全集见 `docs/接口文档_战斗服务.md` §15.2。

| 装备 | 效果 |
| --- | --- |
| 木炭 / 神秘水滴 / 磁铁 | 对应属性（火/水/电）招式威力提升 20% |
| 达人带 | 效果拔群时伤害提升 20% |
| 剩饭 | 每回合末回复最大 HP 的 1/16 |
| 贝壳之铃 | 攻击造成伤害的 1/8 回复自身 HP |
| 先制之爪 | 20% 概率无视速度先手出招（双方均触发时回退速度判定） |
| 进化辉石 | 未最终进化时防御/特防提升 50%（最终进化无效） |

- **获取途径**：
  1. 肉鸽楼层「装备补给」事件随机获得一件（重复获得则落空）；
  2. **商店购买**：商店固定留出装备格位（第 1 段 1 格，第 3 段起 2 格），
     装备池为 `equipment.csv` 全量 77 件，**不再分段解锁**（第 1 段起全部可能上架），
     只按段通胀定价，已拥有的装备不再上架，购买后入库（可重复购买不存在，同一件全库唯一）；
- **穿戴入口**：主菜单队伍面板点击精灵名弹出图鉴弹窗，在弹窗内查看精灵信息与装备库、穿戴/脱下装备。

## 四、游戏流程与节点设计

### 4.1 行动点（AP）机制
- 每段路线固定行动点上限，**行动点耗尽触发本段必然节点（道馆战）**后进入下一段，循环至终点；
- 段开始时 AP 重置至本段上限；**上限数值与敌人强度随进度提升（数值待配置）**；
- **每走完一个路线节点，本段剩余的路线节点整批重新随机生成**（只换节点：AP、段号、金币与
  剧情线标记都不重置）；常驻节点每次都必然入列，因此刷新后仍能再次进入路人 / 野外精灵 / 医院；
- **常驻节点（路人 / 野外精灵 / 医院）走过后可以重复进入，每次进入照常扣 AP，AP 是唯一的限制资源**；
  非常驻节点（商店 / 特殊事件 / 火箭队 / 神兽偶遇）在同一批节点内是一次性的（走过后置灰不可再进），
  下一次刷新时才重新随机判定是否出现。

| 节点/行动 | AP 消耗 | 说明 |
| --- | --- | --- |
| 野外精灵（偶遇） | 1 点 | 有概率消耗为 **0 点** |
| 路人 | 2 点 | — |
| 医院 | 1 点 | — |
| 商店 | 1 点 | 随机出现，随进展商品种类与数量越多 |
| 神兽偶遇（特殊事件） | 1 点 | 仅后期正常偶遇触发时 |
| 神兽偶遇（火箭队线必然触发） | **0 点** | 击败火箭队首领获大师球后必然出现 |
| 火箭队节点 | 2 点 | 高收益高风险 |
| 道馆战 / 四天王 / Boss | 不占用 | AP 耗尽（道馆）或路线终点必然触发 |

### 4.2 节点类型总表

> 节点列表**每走完一个路线节点就整批刷新**（§4.1）：下表的「随机概率出现」不是每段只判定一次，
> 而是每次刷新都重新判定；常驻节点（路人 / 野外精灵 / 医院）每次刷新都必占 3 个槽位。

| 节点 | 生成规则 | 玩法说明 |
| --- | --- | --- |
| 路人 | 常驻（**可重复进入**） | 与路人训练师对战，**胜利获金币；失败仅扣金币** |
| 野外精灵 | 常驻（**可重复进入**） | 遭遇野生宝可梦，可战斗并**捕获**；失败仅扣金币 |
| 医院 | 常驻（**可重复进入**） | 治疗濒死/受伤宝可梦；**恢复途径仅医院与道具** |
| 商店 | 随机概率出现（一次性） | 金币购买道具、回复品、**可携带装备**（技能机待定） |
| 特殊事件 | 低概率、类型多样、带进度限制（一次性） | 神兽偶遇（仅后期）、火箭队（各时期均可能）等 |
| 装备补给 | 随机概率出现（一次性） | 随机获得一件可携带装备（重复获得则落空），可在主菜单图鉴弹窗中穿戴 |
| 道馆战 | AP 耗尽必然触发 | 中期强度门槛、进度里程碑 |
| 四天王连打 | Boss 前必然触发 | 与道馆同级，可失败一次 |
| Boss 冠军战 | 路线终点必然触发 | 最终 Boss，不可失败 |

### 4.3 失败与惩罚规则
| 战斗类型 | 失败处理 |
| --- | --- |
| 路人 / 野外精灵 / 神兽战 | 仅扣金币，不中断 Run；可继续或用金币补给 |
| 火箭队战 / 首领战 / 首领侵略战 | **不可失败**，战败 Run 直接结束 |
| 道馆战 / 四天王 | 可失败一次（大量扣金币）；**重试再败则 Run 结束** |
| Boss 冠军战 | **不可失败**，失败 Run 直接结束 |

### 4.4 濒死与自回血规则
- **濒死**宝可梦无法继续参战，仅能通过**医院节点**或**道具（复活药等）**恢复，不随推进自动回满；
- **战斗中的补位**：己方出战宝可梦在战斗中倒下时，**由玩家从队伍中选择下一只上场宝可梦**
  （不再自动换宠）；选出之前战斗挂起、无法出招/用道具/换宠/逃跑，选出后该宝可梦**满血登场并从中立状态开始**
  （能力等级、寄生种子等临时状态清零）；补位本身**不消耗回合**，敌方不会因此行动；
  只有当**队伍中再无健康宝可梦**时才会战斗失败；
- **节点自回血**：每通过一个节点，未濒死宝可梦恢复**最大 HP 的 1/5**；濒死宝可梦不享受；
- **常驻节点重复进入**：每次进入都算「通过一个节点」，照常触发自回血与 AP 扣除；
  医院重复进入即相当于用 AP 换全队满血 —— 难度上限由 AP 额度决定（见 §4.5 待平衡项）。

## 五、特殊事件进阶规则

### 5.1 神兽偶遇
- 仅**游戏后期**出现，中前期不会遇到；
- **每局只可触发一次**（含大师球必然触发的神兽偶遇），不可重复；
- 战斗判定与普通精灵、路人战一致：失败仅扣金币；
- 火箭队首领战获胜获得**大师球**后可**必然触发一次**神兽偶遇节点（**无需 AP**）。

### 5.2 火箭队节点（高收益 · 高风险）
- **各时期均有概率遇见**；
- 收益：胜利获大量金币，有概率掉落**特殊道具**；
- 风险：难度显著高于常规节点，**不可失败**，战败 Run 直接结束；
- **进入过任意一次**火箭队节点，即开启后期「火箭队抓捕神兽」剧情线。

### 5.3 火箭队剧情线分支
| 玩家行为 | 后续结果 |
| --- | --- |
| 进入过火箭队节点 + 后期选择进入「抓捕神兽」事件 | 与火箭队首领交手（不可失败）；胜利获**大师球**，**必然触发一次神兽偶遇节点** |
| 进入过火箭队节点 + 后期不进入抓捕事件 | 正常挑战冠军；**击败冠军后**触发**首领侵略事件**（与持有神兽的火箭队首领交战） |
| **全程未进入**任何火箭队节点 | 无抓捕/侵略事件；击败冠军即正常通关 |

## 六、一局 Run 的典型节奏（场景流程）
1. 初始选择宝可梦组建队伍出发；
2. 前半程以「路人 + 野外精灵 + 医院」常驻节点推进，随机遭遇商店与低概率特殊事件，积累金币、治疗濒死、提升实力；
3. AP 耗尽 → 道馆战 → AP 重置、敌人增强、进入下一段；
4. 后期若开启火箭队线：出现抓捕事件供选择——**进入**则战首领得大师球并必然触发神兽偶遇；**不进入**则照常推进；
5. 抵达终点：先**四天王连打**（可失败一次），再 **Boss 冠军战**；
6. 结局判定：首领未被提前击败且有剧情线 → 击败冠军后触发**首领侵略战**；未触发剧情线则击败冠军即正常通关；中途战败/重试失败即结束 Run。
