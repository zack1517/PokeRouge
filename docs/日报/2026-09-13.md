### 一、今日完成

- [x] **道具图鉴补启动页入口**（需求方反馈「道具图鉴没有啊」→ 确认是**在启动页找不到入口**）
  - 现状核实：`道具图鉴` 此前只挂在**进入游戏后的主菜单**底部（`MainView#buildActionBar()` 的
    `dex` 按钮 → `MainView.Actions#onShowItemDex()` → `MainController#showItemDex()`），
    而启动页只有「开始游戏 / 继续游戏 / 宝可梦图鉴 / 自定义战斗 / 成就系统 / 设置选项」六个入口，
    因此**没进游戏就看不到它**。`grep "new MainView"` 确认全仓只有一个构造点，接线无缺失。
  - **`StartView`**：在「宝可梦图鉴」下新增第七个胶囊「**道具图鉴**」（`ITEM DEX`），
    构造签名 `StartView(onStartGame, onContinueGame, canContinue, onCustomBattle, onPokedex)`
    → **新增 `onItemDex` 回调**（5 参 → 6 参）；类文档与「六个入口」相关措辞改为七个；
    新增行囊图标 `ICON_BAG`；`start-menu.css` 的 tone 选择器补 `.menu-tone-teal`
    （该选择器内所有 tone 共用同一份配色，此前只有 yellow / blue / crimson / violet / slate）。
  - **`MainController#showItemDexFromStart()`**（新增）：启动页尚未读档、没有 `Player`，
    因此以 **`player = null`** 打开同一个 `ItemDexView`，返回回启动页。
  - **`ItemDexView`**：构造新增 **4 参重载** `(player, background, onBack, backLabel)`
    （启动页传「返回主界面」；原 3 参构造保留，默认「返回主菜单」）；
    `player == null` 时**降级为只读** —— 全部条目按「未拥有」展示、卡片不画穿戴 / 脱下操作
    而显示「进入游戏后可在此直接穿戴 / 脱下装备。」、摘要行省去「已拥有 N 件」。
    数据层 `ItemDexData#build(null)` **本就支持**（既有 9 个用例里多数就是传 `null`），未改动。
  - 口径不变：仍是 **93 件全量**（16 消耗品 + 77 装备）、四档筛选、不做收集解锁。
- [x] **商店装备改为全量上架**（需求方反馈「商店是直接所有装备就可购买，没有分段解锁，昨天不是弄好了吗」）
  - 现状核实：09-12 的第 50 条已把**分段解锁**整个删掉（装备池自第 1 段起全量可取），
    但装备仍是**每段从 77 件里抽签 1~2 格**（`BASE_SHOP_EQUIPMENT_STOCK = 1` /
    `MAX_SHOP_EQUIPMENT_STOCK = 2`）。也就是说「77 件都在池子里」不等于「都能看到、都能买」——
    玩家想买某一件得反复刷商店，与需求方「直接所有装备就可购买」的预期不符。
  - 经一问确认口径：**商店一次性列出全部 77 件装备，玩家想买哪件就买哪件**。
  - **`ShopStock`**：装备分区**不再抽签** —— 删除 `rollEquipment(...)`，
    改为新增 `allEquipmentEntries(segment, owned)`，把 `sellableEquipment(ownedIds)`
    全量转成条目，排序与道具图鉴同口径（**基础价升序 → id 升序**）；
    `forSegment(...)` 变为「`rollConsumables(...)` + `allEquipmentEntries(...)`」。
  - **`RouteConfig`**：装备**不再占格位** —— `shopStockSize` 更名 **`shopConsumableStockSize`**
    （只约束随机上架的消耗品，3 → 6，上限 6），常量同步更名
    `BASE_SHOP_CONSUMABLE_STOCK` / `SHOP_CONSUMABLE_STOCK_PER_SEGMENT` /
    `MAX_SHOP_CONSUMABLE_STOCK`；`shopEquipmentStockSize` 与三个装备格位常量**删除**。
  - **`ShopView`**：新增 `buildSectionLabel(String)`，货架改为两行分区标题
    「**消耗品 · 本次上架 N 件**」/「**装备 · 全部 N 件**」，头部摘要文案一并改写。
  - **口径不变**：已拥有的装备仍不上架（`sellableEquipment` 过滤）、定价与每段 +15% 通胀不变、
    购买分流（消耗品入背包 / 装备入库）、重复购买拦截、售出后下架、大师球不进商店均不变；
