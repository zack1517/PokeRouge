## 1. 模块概述

### 1.1 模块定位

宝可梦系统是游戏的**核心领域模块**，负责：

- **数据模型**：宝可梦个体、种族、技能、性格、能力值等核心实体
- **技能系统**：技能定义、PP 消耗与恢复、学招表
- **队伍管理**：最多 6 只的队伍维护、出战切换
- **初始池**：新游戏时可选的三只初始宝可梦
- **性格系统**：21 种性格及其能力值修正
- **数据加载**：从 classpath CSV 加载全部静态数据（单例 GameData）

### 1.2 包路径

| 包 | 职责 |
|----|------|
| `org.example.pokemon.domain` | 领域模型（Pokemon、Player、Species 等） |
| `org.example.pokemon.service` | 业务服务（PokemonService 接口 + 实现） |
| `org.example.pokemon.infrastructure` | 数据中心（GameData 单例，CSV 加载） |
| `org.example.pokemon.util` | 工具类（ExperienceCalculator、LogUtil） |

### 1.3 依赖方

- **UI 模块**：展示宝可梦信息、选队、队伍查看
- **战斗系统**：伤害结算、治疗、经验获取、技能 PP 消耗
- **肉鸽系统**：奖励生成、野生宝可梦、队伍满员判断
- **存档系统**：游戏状态导出与导入
- **游戏流程系统**：新游戏创建玩家、重置状态

### 1.4 通用约定

| 约定 | 说明 |
|------|------|
| 服务入口 | `PokemonServiceImpl`，构造时自动绑定 `GameData.instance()` |
| 队伍上限 | 6 只（`Player.MAX_PARTY_SIZE`） |
| 技能槽上限 | 4 个（`Pokemon.MAX_MOVE_SLOTS`） |
| 技能 power = 0 | 变化技能（STATUS 分类） |
| 技能 accuracy = -1 | 必中技能 |
| 进化等级 = 0 | 不可进化 |
| 经验曲线 | medium-fast：升级到 n 级需 `round(n³ × 0.8)` 累计经验 |
| 能力值公式 | HP：`floor((2×种族值+IV)×等级/100) + 等级 + 10`；其余：`floor((floor((2×种族值+IV)×等级/100)+5)×性格修正)` |
| 序列化 | 所有 Model 与 PokemonState 实现 `Serializable` |

## 2. 各系统接口清单

> 说明：所有方法均来自 `PokemonService`（业务入口）、`GameData`（静态数据查询）与领域模型（Model）。`PokemonService` 实例获取方式：
>
> ```java
> PokemonService service = new PokemonServiceImpl();
> ```

### 2.1 UI 模块需要的接口

#### 2.1.1 获取宝可梦展示信息

```java
// Pokemon.java
String getName();                  // 显示名：有昵称优先昵称，否则种族名
int getLevel();                    // 等级
int getExp();                      // 累计经验
int getMaxHp();                    // 最大 HP（按公式实时计算）
int getCurrentHp();                // 当前 HP
Stats getStats();                  // 六项能力值
StatusCondition getStatus();       // 异常状态
Nature getNature();                // 性格
Species getSpecies();              // 所属种族
boolean hasType(ElementType type); // 是否拥有指定属性
```

| 参数 | 说明 |
|------|------|
| `type` | 要检查的属性枚举，如 `ElementType.FIRE` |

**UI 场景**：队伍查看页、详情弹窗、战斗面板中的 HP 条（`currentHp/maxHp`）、状态徽章（`getStatus().getDisplayName()`）。

**示例**：

```java
Pokemon p = player.getActive().orElseThrow();
System.out.println(p.getName() + " Lv." + p.getLevel()
        + " HP " + p.getCurrentHp() + "/" + p.getMaxHp()
        + " 属性 " + p.getSpecies().getTypes());
```

#### 2.1.2 获取初始可选池

```java
// PokemonService.java
List<Species> getInitialPool();

// GameData.java（等效查询）
List<Species> getInitialPool();
```

**返回**：固定的 3 只初始种族（妙蛙种子、小火龙、杰尼龟）；数据缺失时抛 `IllegalStateException`。

**UI 场景**：新游戏选队页，展示三只初始宝可梦供玩家选择。

**示例**：

```java
for (Species s : service.getInitialPool()) {
    System.out.println(s.getName() + "（" + s.getCategory() + "）");
}
```

#### 2.1.3 获取队伍列表

```java
// Player.java
List<Pokemon> getParty();       // 队伍列表副本
int getPartySize();             // 队伍当前数量
boolean isPartyFull();          // 是否已满 6 只
```

**返回**：`getParty()` 返回防御性副本，修改副本不影响队伍。

**UI 场景**：队伍查看页、选队界面、出战标记（配合 `getActiveIndex()`）。

#### 2.1.4 获取当前出战精灵

```java
// PokemonService.java
Optional<Pokemon> getActivePokemon();

// Player.java
Optional<Pokemon> getActive();
int getActiveIndex();
```

**返回**：出战精灵存在**且未濒死**时返回包装值，否则为 `Optional.empty()`。

**UI 场景**：战斗面板中展示出战精灵头像与血条。

#### 2.1.5 获取技能信息

```java
// Pokemon.java
List<MoveSlot> getMoveSlots();  // 已装备技能槽（不可变视图）
List<Move> getMoves();          // 已装备技能列表

// Move.java
String getId();                 // 技能 id（如 "ember"）
String getName();               // 中文名（如 "火花"）
ElementType getType();          // 属性
MoveCategory getCategory();     // PHYSICAL / SPECIAL / STATUS
int getPower();                 // 威力（0 = 变化技能）
int getAccuracy();              // 命中率（-1 = 必中）
int getMaxPp();                 // 最大 PP
int getPriority();              // 先制度
boolean isPhysical();           // 是否物理技能
boolean isSpecial();            // 是否特殊技能
boolean isStatus();             // 是否变化技能
```

**UI 场景**：战斗面板技能按钮（显示威力/PP/属性颜色）、图鉴技能详情。

**示例**：

```java
for (Move m : pokemon.getMoves()) {
    System.out.println(m.getName() + " 威力" + m.getPower()
            + " 命中" + m.getAccuracy() + " PP" + m.getMaxPp());
}
```

#### 2.1.6 获取性格列表

```java
// PokemonService.java
List<Nature> getAllNatures();

// Nature.java
String getId();                                    // 如 "adamant"
String getName();                                  // 如 "固执"
Optional<StatModifier> getIncreasedStat();         // 提升的能力项
Optional<StatModifier> getDecreasedStat();         // 降低的能力项
double getModifier(StatModifier stat);             // 修正倍率 1.1/0.9/1.0
```

**UI 场景**：性格查看页、创建宝可梦时的性格选择下拉框。

### 2.2 战斗系统需要的接口

#### 2.2.1 造成伤害

```java
// Pokemon.java
void takeDamage(int damage);
```

| 参数 | 说明 |
|------|------|
| `damage` | 伤害值（≥0） |

**行为**：`currentHp = max(0, currentHp - damage)`；HP 归零时自动置 `status = FAINTED`。

**战斗场景**：攻击结算、灼伤/中毒扣血。

#### 2.2.2 治疗

```java
// Pokemon.java
void heal(int amount);   // 恢复指定 HP，不超过 maxHp；濒死状态无效
void fullHeal();         // 满血 + 清除所有异常状态

// PokemonService.java
void healPokemon(Pokemon pokemon); // 等价于 fullHeal
void healParty();                  // 恢复当前队伍全员
```

**战斗场景**：技能回血（`heal`）、战斗结束恢复（`healParty`）、道具复活（`fullHeal` 可清除 FAINTED）。

#### 2.2.3 获取当前出战精灵 / 切换出战精灵

```java
// PokemonService.java
Optional<Pokemon> getActivePokemon();
boolean switchActivePokemon(int index);

// Player.java
boolean switchActive(int index);
```

**行为**：`switchActive` 索引越界或目标精灵濒死时返回 `false`。

**战斗场景**：回合开始取出战者；换人操作（换入濒死者失败）。

#### 2.2.4 技能 PP 消耗和恢复

```java
// MoveSlot.java
boolean isExhausted();          // PP 是否耗尽（≤0）
void usePp();                   // 消耗 1 点 PP（耗尽时无效果）
void restorePp(int amount);     // 恢复 PP，不超过 maxPp
void fullRestore();             // PP 完全恢复
int getCurrentPp();             // 当前 PP
int getMaxPp();                 // 最大 PP
```

**战斗场景**：释放技能前检查 `isExhausted()`，释放后 `usePp()`；回合结束或道具恢复 PP。

**示例**：

```java
MoveSlot slot = pokemon.getMoveSlots().get(0);
if (!slot.isExhausted()) {
    // ... 结算技能 ...
    slot.usePp();
} else {
    System.out.println("PP 不足，无法使用该技能");
}
```

#### 2.2.5 经验获取和升级

```java
// Pokemon.java
void gainExp(int expGain);      // 累计经验；满足条件自动连续升级并回满 HP
int expToNextLevel();           // 距下一级所需经验
int getExp();                   // 当前累计经验
int getLevel();                 // 当前等级

// PokemonService.java（推荐，附带成长事件）
List<GrowthEvent> gainExp(Pokemon pokemon, int exp);
```

**行为**：`PokemonService.gainExp` 内部调用 `Pokemon.gainExp`，并生成 `GrowthEvent` 列表（LEVEL_UP / LEARN_MOVE / EVOLUTION），升级区间内自动学招（`pokemon.learnMove`）。

**战斗场景**：战斗胜利结算经验；事件列表用于 UI 播报"升级了！学会了XX！进化了！"。

#### 2.2.6 检查是否濒死

```java
// Pokemon.java
boolean isFainted();            // HP≤0 或 status=FAINTED

// Player.java
boolean isPartyAllFainted();    // 队伍全员濒死
boolean hasHealthyPokemon();    // 队伍中是否存在未濒死者

// PokemonService.java
boolean isPartyAllFainted();
```

**战斗场景**：战斗失败判定（`isPartyAllFainted`）、目标濒死跳过行动。

#### 2.2.7 获取技能列表 / 能力值

```java
// Pokemon.java
List<MoveSlot> getMoveSlots();  // 技能槽（含 PP 状态）
List<Move> getMoves();          // 技能列表
Stats getStats();               // 六项能力值（含性格修正，实时计算）
int getMaxHp();
int getCurrentHp();

// PokemonService.java
double getNatureModifier(Nature nature, StatModifier stat); // 性格修正倍率
```

**战斗场景**：伤害公式计算（物理攻/防 vs 特殊攻/防，按技能分类取对应能力值）。

### 2.3 肉鸽系统需要的接口

#### 2.3.1 创建宝可梦（奖励生成）

```java
// PokemonService.java
Pokemon createPokemon(String speciesId, int level);
Pokemon createPokemon(String speciesId, int level, Nature nature);
```

| 参数 | 说明 |
|------|------|
| `speciesId` | 种族 id（如 `"pikachu"`）；不存在时抛 `IllegalArgumentException` |
| `level` | 初始等级 |
| `nature` | 指定性格；省略时使用默认性格（勤奋 HARDY） |

**行为**：个体值（IV）六项随机（0-31）。

**肉鸽场景**：奖励宝可梦生成——指定种族生成指定性格的入队奖励。

#### 2.3.2 创建野生宝可梦

```java
// PokemonService.java
Pokemon createWildPokemon(String speciesId, int aroundLevel);
```

| 参数 | 说明 |
|------|------|
| `aroundLevel` | 目标等级 |

**行为**：等级在 `aroundLevel ± 2` 内随机（最低 1 级），性格从全部 21 种中随机。

**肉鸽场景**：遭遇战生成野生敌人。

#### 2.3.3 添加宝可梦到队伍 / 满员判断

```java
// PokemonService.java
boolean addPokemonToParty(Pokemon pokemon);
// 注意：当前玩家未创建（getPlayer()==null）时返回 false

// Player.java
boolean addPokemon(Pokemon pokemon); // 队伍满 6 只时返回 false
boolean isPartyFull();
int getPartySize();
```

**肉鸽场景**：奖励选择后入队；满员时提示"队伍已满，需替换或放弃"。

#### 2.3.4 获取所有性格（随机性格）

```java
// PokemonService.java
List<Nature> getAllNatures();

// GameData.java（等效）
List<Nature> getAllNatures();
```

**肉鸽场景**：随机事件"性格重置"（注意：`setNature` 暂未实现，性格当前不可变）。

### 2.4 存档系统需要的接口

#### 2.4.1 导出当前状态

```java
// PokemonService.java
PokemonState exportState();
```

**返回**：包含当前玩家（可为 null）与保存时间戳的 `PokemonState`。

**存档场景**：存档时将 `PokemonState` 序列化（Java 原生序列化或 JSON）持久化。

#### 2.4.2 导入历史状态

```java
// PokemonService.java
void importState(PokemonState state);
```

| 参数 | 说明 |
|------|------|
| `state` | 反序列化得到的存档对象 |

**行为**：将 `state.getPlayer()` 设为当前玩家。

**存档场景**：读档时恢复玩家队伍。

#### 2.4.3 PokemonState 数据结构

```java
public class PokemonState implements Serializable {
    public PokemonState(Player player, long timestamp); // 构造（供反序列化框架使用）
    public Player getPlayer();   // 玩家及其队伍（Player、Pokemon 等均可序列化）
    public long getTimestamp();  // 保存时间戳（毫秒）
}
```

**说明**：`Player` → `List<Pokemon>` → `Species/Move/MoveSlot/Stats/Nature` 整条对象图均实现 `Serializable`，可直接整体序列化；`GameData` 静态数据不参与存档，读档后由单例重新加载。

### 2.5 游戏流程系统需要的接口

#### 2.5.1 创建玩家

```java
// PokemonService.java
Player createPlayer(String name);
```

| 参数 | 说明 |
|------|------|
| `name` | 玩家姓名 |

**行为**：创建新 `Player` 并设为当前玩家（覆盖旧的）。

**流程场景**：新游戏开始，输入姓名创建训练家。

#### 2.5.2 重置玩家状态

```java
// PokemonService.java
void resetPlayer();   // 当前玩家置为 null
Player getPlayer();   // 当前玩家（未创建时为 null）
```

**流程场景**：返回主菜单、重新开始游戏。

#### 2.5.3 获取玩家信息 / 初始池

```java
// PokemonService.java
Player getPlayer();
List<Species> getInitialPool();

// Player.java
String getName();
List<Pokemon> getParty();
```

**流程场景**：新游戏流程 = `createPlayer` → 选择 `getInitialPool()` 中的一只 → `addPokemonToParty` → 进入战斗/地图。

## 3. 数据模型说明

### 3.1 Pokemon.java — 宝可梦个体

| 方法 | 返回 | 说明 |
|------|------|------|
| `getUuid()` | `String` | 全局唯一标识 |
| `getSpecies()` | `Species` | 所属种族 |
| `getName()` | `String` | 显示名（昵称优先，否则种族名） |
| `getLevel()` / `getExp()` | `int` | 等级 / 累计经验 |
| `getIvs()` | `Stats` | 个体值（0-31） |
| `getNature()` | `Nature` | 性格 |
| `getStatus()` | `StatusCondition` | 异常状态 |
| `getMaxHp()` / `getCurrentHp()` | `int` | 最大 / 当前 HP |
| `getStats()` | `Stats` | 六项能力值（含性格修正） |
| `isFainted()` | `boolean` | 是否濒死 |
| `expToNextLevel()` | `int` | 距下一级所需经验 |
| `hasType(ElementType)` | `boolean` | 是否拥有指定属性 |
| `getMoveSlots()` | `List<MoveSlot>` | 技能槽（不可变视图） |
| `getMoves()` | `List<Move>` | 已装备技能列表 |
| `hasMove(String moveId)` | `boolean` | 是否已学会指定技能 |
| `canLearnMove(Move)` | `boolean` | 是否满足学习条件 |
| `learnMove(Move)` | `void` | 学招（未满 4 槽追加，否则替换末位） |
| `takeDamage(int)` | `void` | 受到伤害，归零进入濒死 |
| `heal(int)` | `void` | 恢复 HP（濒死无效，不超上限） |
| `fullHeal()` | `void` | 满血 + 清除状态 |
| `gainExp(int)` | `void` | 获得经验，自动连续升级并回满 HP |

**构造**：`new Pokemon(Species species, int level, Stats ivs, Nature nature)`（nature 为 null 时用 HARDY）。

### 3.2 Player.java — 训练家

| 方法 | 返回 | 说明 |
|------|------|------|
| `getName()` | `String` | 玩家姓名 |
| `getParty()` | `List<Pokemon>` | 队伍副本 |
| `getPartySize()` | `int` | 队伍数量 |
| `isPartyFull()` | `boolean` | 是否满 6 只 |

| `getActiveIndex()` | `int` | 出战索引（-1 表示无） |
| `switchActive(int)` | `boolean` | 切换出战（越界/濒死失败） |
| `hasHealthyPokemon()` | `boolean` | 是否有未濒死者 |
| `getHealthyPokemon()` | `List<Pokemon>` | 未濒死者列表 |
| `isPartyAllFainted()` | `boolean` | 是否全员濒死 |
| `healParty()` | `void` | 全员完全恢复 |

**构造**：`new Player(String name)`。

### 3.3 Species.java — 种族

| 方法 | 返回 | 说明 |

### 3.5 Nature.java — 性格

| 成员 | 说明 |
|------|------|
| `Nature.HARDY` 等 21 个静态常量 | 勤奋、怕寂寞、勇敢、固执、顽皮、大胆、悠闲、淘气、乐天、胆小、急躁、爽朗、天真、内敛、慢吞吞、冷静、马虎、温和、温顺、慎重、仔细 |
| `getId()` / `getName()` | id（如 `"adamant"`）/ 中文名（如 `"固执"`） |
| `getIncreasedStat()` | `Optional<StatModifier>` 提升的能力项 |
| `getDecreasedStat()` | `Optional<StatModifier>` 降低的能力项 |
| `getModifier(StatModifier)` | `double` 修正倍率：提升 1.1 / 降低 0.9 / 无修正 1.0 |

### 3.6 Stats.java — 能力值

| 方法 | 说明 |
|------|------|
| `getHp()/getAttack()/getDefense()/getSpAttack()/getSpDefense()/getSpeed()` | 六项能力值 |
| `getHpIv()/getAttackIv()/.../getSpeedIv()` | 同值别名（IV 语义，0-31） |
| `static Stats randomIv()` | 生成六项随机个体值（0-31） |

**构造**：`new Stats(int hp, int attack, int defense, int spAttack, int spDefense, int speed)`。

### 3.7 MoveSlot.java — 技能槽

| 方法 | 返回 | 说明 |
|------|------|------|
| `getMove()` | `Move` | 绑定的技能 |

| `restorePp(int)` | `void` | 恢复 PP（不超上限） |

### 5.2 战斗：获取出战精灵 → 造成伤害 → 检查濒死 → 获取经验

```java
import java.util.List;
import org.example.pokemon.domain.GrowthEvent;
import org.example.pokemon.domain.Pokemon;
import org.example.pokemon.service.PokemonService;
import org.example.pokemon.service.PokemonServiceImpl;

PokemonService service = new PokemonServiceImpl();

// 回合开始：取出战精灵
Pokemon active = service.getActivePokemon().orElseThrow();
System.out.println("出战：" + active.getName() + " HP " + active.getCurrentHp() + "/" + active.getMaxHp());

// 敌方攻击结算
active.takeDamage(15);

// 濒死检查
if (active.isFainted()) {
    System.out.println(active.getName() + " 倒下了！");
    // 尝试换人
    service.switchActivePokemon(1);
}

// 胜利结算：获得经验，处理成长事件
List<GrowthEvent> events = service.gainExp(active, 120);
for (GrowthEvent e : events) {
    switch (e.getType()) {
        case LEVEL_UP   -> System.out.println("升级到 " + e.getNewLevel() + " 级！");
        case LEARN_MOVE -> System.out.println("学会了 " + e.getLearnedMove().getName() + "！");
        case EVOLUTION  -> System.out.println("进化成了 " + e.getEvolvedTo().getName() + "！");
    }
}

// 技能 PP 消耗
var slot = active.getMoveSlots().get(0);
if (!slot.isExhausted()) {
    slot.usePp();
} else {
    System.out.println("PP 不足！");
}
```

### 5.4 存档：导出 PokemonState → 序列化保存

```java
import java.io.FileOutputStream;
import java.io.ObjectOutputStream;
import org.example.pokemon.domain.PokemonState;
import org.example.pokemon.service.PokemonService;
import org.example.pokemon.service.PokemonServiceImpl;

PokemonService service = new PokemonServiceImpl();

// 存档：导出状态并序列化（Player → Pokemon 整条对象图均可序列化）
PokemonState state = service.exportState();
try (ObjectOutputStream out = new ObjectOutputStream(new FileOutputStream("save.dat"))) {
    out.writeObject(state);
}

// 读档：反序列化后导入
try (var in = new java.io.ObjectInputStream(new java.io.FileInputStream("save.dat"))) {
    PokemonState loaded = (PokemonState) in.readObject();
    service.importState(loaded);
}
System.out.println("读档完成，玩家：" + service.getPlayer().getName()
        + "，存档时间：" + state.getTimestamp());
```

## 6. 已知限制与注意事项

| 事项 | 说明 |
|------|------|
| `setNature(Pokemon, Nature)` | 暂未实现（Pokemon 性格字段不可变），调用无效果 |
| 进化替换 | `evolve(Pokemon)` 只返回目标 `Species`，具体替换操作由调用方处理 |
| 学招上限 | 超过 4 个技能槽时 `learnMove` 替换最后一个槽位 |
| 濒死治疗 | `heal(int)` 对濒死精灵无效，需 `fullHeal()` 或 `healParty()` |
| 数据缺失 | `GameData` 加载失败会抛 `RuntimeException`；初始池缺失抛 `IllegalStateException`；未知种族 id 抛 `IllegalArgumentException` |
| 返回集合 | `getParty()/getTypes()/getLearnableMoves()/getMoveSlots()` 均为副本或不可变视图，外部修改不影响内部状态 |
