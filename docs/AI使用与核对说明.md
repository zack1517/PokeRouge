# AI 使用与核对说明

> 本文档记录 PokeRouge 项目自启动以来使用 AI 辅助开发的过程、人工核对结果与问题留痕，供课程验收与组内复盘。
> 详细版见本文档；README 第六节保留核对原则与入口指引。

## 一、核对原则（来自课程）

1. **一次只让 AI 生成一类文件**，生成后立即用 `mvn clean compile` 验证；
2. 核对三点：**版本匹配**（JavaFX 与 JDK 17 对齐）、**最小性**（无多余依赖）、**可构建**；
3. AI 不确定处一律标注 `[待确认]`，人工核对定稿；
4. 功能交付必带单元测试并全量跑通 `mvn test`，关键判定分支人工抽查；
5. 实现与文档同步升级（需求/接口文档走版本记录机制）。

## 四、小结

- **AI 与人工的分工**：AI 负责按需求生成实现与测试；人工负责核对判定分支、运行验证、数据口径与文档一致性；
- **问题发现手段**：编译验证（`mvn clean compile`）→ 全量测试（`mvn test`）→ 静态核查（包依赖、随机源）→ 探针实测（jshell）→ 人工抽查关键逻辑；
- **累计质量**：截至最近一轮迭代，14 个测试类共 124 个用例全绿（`mvn clean test` 通过）；
- **文档同步**：需求文档、战斗服务接口文档（v1.10）、UI 模块接口文档（v0.1.10）均与实现同步升级。
